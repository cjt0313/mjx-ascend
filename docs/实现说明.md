# 实现说明

## 固定执行链

`python -m mjx_ascend` 设置 NPU 后端并加载场景，先用原生 MuJoCo 独立计算相同控制的 CPU 参考，再将原始初态转换为 MJX，连续执行 NPU 物理步。NPU 步之间不使用 CPU 状态重新初始化。

场景注册圆柱碰撞扩展后，由 `staged_libero_step.staged_kernels` 按原 MJX 物理阶段执行。这里只改变执行组织和已验证的数值实现，不降低求解器迭代次数、精度或接触容量。大批量 mesh pair 分块是为控制中间张量，不等同于融合内核。

## 必要适配

| 模块 | 作用 |
|---|---|
| `libero_native_adapter` / `native_cylinder_mesh` | 圆柱 support/GJK 与严格分离结果接入；不可支持的情况显式失败 |
| `native_mesh_broadphase` | group/chunk 保守球界筛选；无法证明安全时保留原计算 |
| `native_candidate_packing` | 稳定候选打包、固定槽恢复和容量溢出时完整路径 |
| `native_contact_templates` | 预先准备不变接触参数，几何姿态仍实时读取 |
| `native_contained_box_faces` | pinned MuJoCo 3.2.7 box 面接触约定 |
| `native_elliptic_hessian` | 通过块乘积重排 Hessian，避免约束空间平方矩阵 |
| `native_elliptic_linesearch` | 防止浮点舍入导致应非负的平方范数出现负值 |
| `capture` / `validation` / `backend` | 场景 hash、版本、数值门槛、设备选择和原生调用保护 |

固定参数：mesh batch16，mesh asset61 batch128，cylinder batch8，cylinder candidate capacity8；保守 group/chunk broadphase、接触模板、box 修正、稳定线搜索与 factored Hessian 均启用。对其他模型不能直接复用这些 asset ID 和适用条件。

## 碰撞输出

本场景包含 PLANE–BOX、PLANE–MESH、BOX–BOX、BOX–MESH、MESH–MESH、CYLINDER–BOX、CYLINDER–MESH。前五类每 pair 四槽，圆柱扩展每 pair 一槽，共 15,807 候选对 / 62,709 输出槽。

组输入为有序 `geom[B,2]`、live `geom_xpos/geom_xmat` 及静态尺寸/凸包拓扑；输出 `dist[B*K]`、`pos[B*K,3]`、`frame[B*K,3,3]`。被安全剔除的 inactive 槽可以保存球界下界、中点和单位 frame，不能当作精确最近距离。mesh 按凸包处理。

## 后端

PJRT 后端将 JAX/XLA 运算映射到 ACLNN。当前配置未实现完整物理阶段的算术融合；很多小算子和同步造成显著开销。后端补丁包含实际路径需要的布局、索引、控制流、整数运算和异步拷贝修复。

整理时删除了从未进入本回放路径的自定义 pose 内核及其硬编码路径，以及不可达的 EPA/触碰研究分支和失败现场归档入口。保留已验证整数折叠，不保留后续未完成验收的 gather 折叠候选。改动后的插件必须重新构建并回归，不能沿用旧二进制 hash 作为新构建证明。

## 上游

- [MJX collision driver 3.2.7](https://github.com/google-deepmind/mujoco/blob/3.2.7/mjx/mujoco/mjx/_src/collision_driver.py)
- [MJX convex collisions 3.2.7](https://github.com/google-deepmind/mujoco/blob/3.2.7/mjx/mujoco/mjx/_src/collision_convex.py)：`plane_convex`、`box_box`、`convex_convex`。
- [MJX solver 3.2.7](https://github.com/google-deepmind/mujoco/blob/3.2.7/mjx/mujoco/mjx/_src/solver.py)：`solve`、`_update_constraint`、`_update_gradient`、`_linesearch`。

JAX 路径由 XLA 生成设备内核，没有逐类碰撞对应的固定手写 CUDA 文件。本仓库不引入不同算法的 Warp 碰撞替换。
