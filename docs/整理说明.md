# 仓库整理范围

本仓库从完整 MuJoCo 源码树整理为独立的 Ascend 固定场景复现项目，保留原 Git 历史。MuJoCo/MJX 作为固定版本依赖安装，不维护另一份无关引擎源码。

保留：固定运行入口、有效数值适配、场景与75步输入/参考、源码后端补丁、中文文档和相关回归测试。

移除：历史实验入口、未验证配置、失败快照/报告集、GPU对照研究资料、未使用pose内核、EPA/触碰研究分支、个人路径与构建产物。

保守筛选不能证明安全或候选溢出时的完整路径属于必要的正确性保护，予以保留；不允许吞错或CPU静默回退。数值清理前后分别执行回归，并用新插件验证固定轨迹。

原工作区历史资料未删除；不属于此仓库发布内容。编译产物、日志和输出在被忽略的目录中保存，验证文档只记录本次结论与复现指令。
