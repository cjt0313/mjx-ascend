# 场景与参考数据

场景为 LIBERO Spatial 中的 `pick_up_the_black_bowl_between_the_plate_and_the_ramekin_and_place_it_on_the_plate`。本仓库保留捕获时的编译模型和低层控制序列，运行的是固定控制物理回放，不是执行自然语言任务的策略。

## 文件

- `scene/model.mjb.gz`：原始 MuJoCo 3.2.7 二进制的无损 gzip。模型内嵌 mesh/纹理，解压后 SHA256 与捕获模型一致；不能改用其他 MuJoCo 版本解释二进制。
- `scene/replay.npz`：`initial_state[415]` FP64 完整 integration state；`controls[75,9]` FP32；`initial_qpos`、`initial_qvel`、`initial_time` 用于恢复后的交叉检查。
- `scene/reference.npz`：75 个已验证 NPU 状态的 FP32 qpos/qvel/time，不是 CPU 参考。CPU 参考每次由相同模型、初态和控制重新生成。
- `scene/manifest.json`：版本、状态 specification、模型配置 hash、压缩及解压模型 hash、输入和参考文件 hash。

全部精简数据由原捕获直接提取，不重写几何或控制。控制先转 FP32，CPU 和 NPU 接收相同控制值，保持原验证协议。去掉的是审计对象、随机状态、观测和控制器历史，不是物理初态。

## 完整性

加载时拒绝版本不匹配、文件 hash 不匹配、错误状态长度、非有限输入或模型配置变化。解压文件留在本次输出的 cache 目录，不修改仓库场景文件。输出目录不会覆盖已有结果。

## 范围

75 步仅为 0.15 秒仿真时间（每步 0.002 秒），包含 19 个有接触的状态。轨迹通过不能证明完整任务成功、长期稳定性或任意接触类型支持。不要将参考数组用于覆盖运行状态；它只用于独立验收。
